# Análise de Faturamento com Python e SQL

##  O Desafio
Este projeto foi desenvolvido para responder a perguntas rápidas de negócios, simulando a necessidade de uma equipe de vendas. O objetivo foi criar e popular um banco de dados relacional do zero via código e extrair insights operacionais.

##  Tecnologias Utilizadas
- **Linguagem:** Python
- **Banco de Dados:** SQLite
- **Manipulação de Dados:** Pandas

##  O que o código faz
Através de consultas SQL embutidas no Python, o script automatiza:
1. A criação de um banco de dados e de tabelas de vendas.
2. A filtragem de produtos com base no valor unitário e faturamento total.
3. A ordenação estratégica dos resultados para tomada de decisão.
